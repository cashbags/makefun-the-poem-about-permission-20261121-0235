A Node 22 program that writes one short poem about agency — the power to ask and to be given — to /output/entry.txt. Nine lines, 250 Unicode code points: a question carried like a bowl of water, a door opened before the knock, and the power passing to the other side.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
